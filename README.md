# Sabine van Vessem

**Minder boem boem boem, meer groove.**

Website voor DJ Sabine van Vessem — een nieuwe naam om in de gaten te houden in de elektronische muziekscene.

🔗 **Live:** https://nocturnaltomato.github.io/sabine-van-vessem/

## Wat zit erin

- Intro-animatie: *boem boem boem* → *groove.*
- Hero met live videoloop, neon-gloed en een equalizer die meebeweegt met de muziek
- Drie live reels uit haar set; de visuals reageren op het echte geluid
- **Groove Machine**, volledig gesynthetiseerd (geen samples). De audio uit de filmpjes is geanalyseerd: 128 BPM, A mineur/frygisch, strakke korte kick, korte offbeat-hats (~65 ms), clap op 2 en 4 en een hypnotische riff op één toon. Daarop zijn alle geluiden gebouwd: gestemde kick met klik en sidechain, clap, metalen hats, rim, shaker, rollende bas, stabs en pads, met galm, ping-pong-echo, glue-compressor en limiter. Bediening: schuif van *Boem boem boem* naar *Meer groove*, DJ-filter, swing, echo, bas, tempo en een Drop-knop met opbouw
- **Jouw melodie**: zet in een raster van 16 stappen je eigen melodie in de toonsoort van haar set, kies Acid, Pluk of Bel en deel je melodie via een link
- Ogen die je volgen — want dit is een naam om in de gaten te houden

Puur HTML, CSS en JavaScript, zonder build-stap. Gehost op GitHub Pages.
