# Sabine van Vessem

**Minder boem boem boem, meer groove.**

Website voor DJ Sabine van Vessem — een nieuwe naam om in de gaten te houden in de elektronische muziekscene.

🔗 **Live:** https://nocturnaltomato.github.io/sabine-van-vessem/

## Wat zit erin

- Intro-animatie: *boem boem boem* → *groove.*
- Hero met live videoloop, neon-gloed en een equalizer die meebeweegt met de muziek
- Drie live reels uit haar set; de visuals reageren op het echte geluid
- **Groove Machine**: een techno-synth die live in je browser draait (Web Audio). Schuif van *Boem boem boem* naar *Meer groove* en hoor het verschil
- Ogen die je volgen — want dit is een naam om in de gaten te houden

Puur HTML, CSS en JavaScript, zonder build-stap. Gehost op GitHub Pages.

## Lokaal draaien

```bash
python3 -m http.server
```

Open daarna http://localhost:8000.
