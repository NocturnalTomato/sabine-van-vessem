# Sabine van Vessem

**Minder boem boem boem, meer groove.**

Website voor DJ Sabine van Vessem — een nieuwe naam om in de gaten te houden in de elektronische muziekscene.

🔗 **Live:** https://nocturnaltomato.github.io/sabine-van-vessem/

## Wat zit erin

- Intro-animatie: *boem boem boem* → *groove.*
- Hero met live videoloop, neon-gloed en een equalizer die meebeweegt met de muziek
- Drie live reels uit haar set; de visuals reageren op het echte geluid
- **Groove Machine**, gebouwd op haar eigen set. De audio uit de filmpjes is geanalyseerd (128 BPM, toonsoort A mineur/frygisch, hypnotische riff op één toon) en er zijn loops van 4 maten uit gesneden (`assets/audio`). Haar echte geluid draait strak op de grid, aangevuld met een live synth in dezelfde toonsoort: gestemde kick met sidechain-pomp, rollende bas, resonerende riff, 808-hats, galm en ping-pong-echo. Met een DJ-filter, Chop (hakt haar set in stukjes en stottert), Drop-knop met opbouw, en een schuif van *Boem boem boem* naar *Meer groove*
- Ogen die je volgen — want dit is een naam om in de gaten te houden

Puur HTML, CSS en JavaScript, zonder build-stap. Gehost op GitHub Pages.
